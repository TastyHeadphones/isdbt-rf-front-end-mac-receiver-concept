# EMI/EMC Notes

## Prototype Controls

- Include shielding-can footprints over RF-sensitive sections.
- Add common-mode mitigation options near external interfaces.
- Keep switching regulators away from tuner input zone.

## Validation Planning

- Perform near-field probing during bring-up.
- Run pre-compliance scans before committing next PCB revision.
- Track emissions regressions per layout revision.
