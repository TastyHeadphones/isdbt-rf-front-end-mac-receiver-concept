# Stack-Up Recommendation

## Recommended Prototype Stack-Up

- 4-layer minimum for concept prototype:
  1. Top: components + controlled RF/high-speed routing
  2. L2: solid ground plane
  3. L3: power distribution and secondary signals
  4. Bottom: low-speed routing and debug

## When to Move to 6 Layers

- If RF isolation, clock quality, or high-speed routing congestion is insufficient.
- If EMI pre-scan indicates coupling problems requiring improved reference control.
