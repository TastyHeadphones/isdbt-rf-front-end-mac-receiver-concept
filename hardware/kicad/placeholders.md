# Placeholder Policy

Placeholders are used where vendor/part commitment is intentionally deferred. Every placeholder must include:

- electrical function
- interface type
- required voltage rails
- expected clock/reset dependencies
- selection criteria

Placeholder IDs in schematics should use prefixes:

- `TUNER_X*`
- `DEMOD_X*`
- `BRIDGE_X*`
- `REG_X*`
