# Test Points

## Required Test Points

- `TP_5V_IN`
- `TP_3V3_DIG`
- `TP_3V3_RF`
- `TP_1V8_CORE`
- `TP_1V2_CORE` (if used)
- `TP_CLK_REF`
- `TP_RESET_N`
- `TP_I2C_SCL`, `TP_I2C_SDA`
- `TP_LOCK_STATUS`

## Measurement Guidance

- Provide ground reference pads adjacent to high-priority points.
- Use loop-style points or pads suitable for low-inductance probing on clocks/rails.
- Label test points on silkscreen for repeatable lab procedures.
